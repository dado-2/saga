# saga

---

## 🧠 What This Project Does

This is a simple front-end site (HTML + CSS) that simulates:

- Student landing page
- Group selection visuals
- Information display with images
- Visual design for academic guidance platform

> ⚠️ This project does not include backend logic or real data storage. It is a **static** preview of the final system.

---

## ❌ Why We Didn't Use PostgreSQL

PostgreSQL is a real database — it stores and manages user data like student names, grades, and payments.

But for now:

- This project has **no backend/server**
- It doesn’t handle logins, real payments, or real grades
- So there's **no need for a database** yet!

This is just a pretty picture of how the real thing would work.
